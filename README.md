
# ChainRush — AI-Powered Financial Fraud Detection

## Overview
ChainRush is a financial fraud detection project designed to
combine machine learning and graph analytics to identify
suspicious transactions and potentially fraudulent networks.

## Project Components
- Anomaly detection using Isolation Forest
- Behavioral feature engineering
- Graph analytics using NetworkX
- Backend APIs using FastAPI
- Real-time transaction streaming using WebSockets
- Containerization using Docker Compose
- Risk scoring and explainability

## Technology Stack
Python, scikit-learn, NetworkX, FastAPI, WebSockets,
Docker, Docker Compose, React
